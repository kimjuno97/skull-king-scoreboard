# 스컬킹 점수판

최대 8명이 사용하는 모바일 스컬킹 점수판입니다.

접속 주소: https://kimjuno97.github.io/skull-king-scoreboard/

- 기본 인원은 6명이며 이름은 위티, 루시, 이든, 엠버, 로건, 알피 순서입니다. 이름과 인원은 변경할 수 있습니다.
- PC에서는 참가자는 세로, 1~10라운드는 가로로 표시합니다.
- 모바일에서는 라운드 선택기로 한 라운드씩 보며 여섯 참가자의 이름·점수·합계를 한 화면에서 확인합니다. 점수 조절 버튼이 표를 가리지 않도록 공간을 확보합니다.
- 점수 칸을 선택하고 우측 하단의 −10 / +10 버튼으로 기록합니다.
- 0점 기록, 칸 비우기, 합계와 공동 순위를 지원합니다.
- 입력 내용은 현재 페이지 메모리에만 있으며 서버에 전송하거나 자동 저장하지 않습니다.
- 입력 후 새로고침·페이지 이동·탭 닫기 시 브라우저 이탈 확인창을 요청합니다. 모바일 앱 강제 종료 등은 브라우저 특성상 감지하지 못할 수 있습니다.

## 실행과 수정

배포 원본은 `index.html`입니다. 설치나 빌드 없이 파일을 브라우저에서 직접 열어도 사용할 수 있습니다.
기존 한국어 파일명의 로컬 점수판은 보관용 복사본이며 배포에 포함하지 않습니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다. `index.html`을 수정해 `main`에 푸시하면 자동으로 갱신됩니다.
